# 🍽️ Restaurant Review Web Application

This is a **Restaurant web application** built using Django as a final probation project, assigned by my project manager to assess my full-stack development skills. The application allows users to browse and search for restaurants, filter them by various criteria, and read or write reviews—similar in style to platforms like **Tripadvisor** or **Zomato**.

## 🎯 Objective

The goal was to build a dynamic, searchable, and user-interactive restaurant platform using Django. This project tested my ability to design database models, implement filtering, manage user-generated content, and build an intuitive UI/UX.

## 🔧 Tech Stack

- **Python 3.x**
- **Django 3.x**
- **SQLite3** (development DB)
- **HTML5, CSS3, Bootstrap**
- **JavaScript & jQuery**
- **Django Filters** (for search/filter logic)
- **Django Messages Framework**

## 🚀 Key Features

- 🔍 **Search & Filtering**
  - By city, state
  - Veg / Non-Veg options
  - Average rating
  - Cost for two
  
- 📋 **Restaurant Listings**
  - Clean card-based design
  - Detail page with full description

- ✍️ **User Reviews**
  - Registered users can add reviews
  - Star rating system (1 to 5)
  - Reviews displayed on restaurant detail pages

- 🔐 **Authentication**
  - User registration and login
  - Secure review posting

- 📊 **Admin Panel**
  - Manage restaurants, locations, and reviews
